适配上游任务生命周期更新，改善多设备 Codex、Claude 任务识别，并加入可选的屏幕流光提醒。

- 修复长日志、不完整记录和迟到事件造成的任务状态误判，区分完成与中断
- 按任务轮次和子智能体跟踪权限请求，避免其他任务的进展误清等待状态
- 完善 Claude 工具失败、停止失败与结束确认，避免子智能体结束影响主任务
- 屏幕流光覆盖本机和远端 Codex、Claude 任务，默认关闭，睡眠时暂停，重连不重放历史提醒
- 改善菜单面板关闭、额度数字动画和热力图展示，完善剩余额外额度的显示
- 仓库接入可选的 Bark Issue 提醒，在 GitHub Actions 中配置，不占用 Mac 后台资源

Codex 账户功能最低要求 `0.145.0`，Hook 最低要求 `0.150.0`。升级后会从保留的原始 Hook 日志重建统计，原始日志、用量中心数据库和账号账本保留；旧日志没有记录的中断次数显示为不可用。

同一个安装包支持 Apple 芯片和 Intel，沿用开发签名，未经过 Apple 公证。首次安装将 `CodexBar.app` 拖入 `/Applications`；如被系统阻止，在“系统设置 > 隐私与安全性”中选择“仍要打开”。已有用户可通过应用内检查更新升级，防睡眠与自动重置沿用原有后台授权。
